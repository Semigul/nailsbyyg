# Domain Docs

This repository uses a single-context domain layout.

Before exploring the codebase, read:

- `CONTEXT.md` at the repository root, when it exists.
- Relevant decisions under `docs/adr/`.

If these files do not exist, proceed silently. Domain-modeling skills create them when terminology or architectural decisions are actually resolved.

Use terminology defined in `CONTEXT.md` consistently. If proposed work conflicts with an existing ADR, surface the conflict explicitly instead of silently overriding the decision.
